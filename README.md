# محاسبات ریاضی | MATH DASH

**بازی آموزشی تمرینی محاسبات ریاضی**  
پدیدآورنده: **آرش سلیمی**  
شناسه پروژه: `MATH-DASH-001`  
نسخه هدف: `0.1.3`

## فناوری
- HTML, CSS, JavaScript
- Vite
- Capacitor 6 برای بسته‌بندی اندروید
- ذخیره رکوردها در حافظه محلی دستگاه

## امکانات نسخه 0.1.3
- شش حالت: ترکیبی، جمع، تفریق، ضرب، تقسیم و جدول ضرب
- سه سطح دشواری، دو بازه عددی و سه مدت تمرین
- نمایش اعداد فارسی یا انگلیسی
- چهار گزینه برای هر پرسش
- زمان‌سنج، امتیازدهی و بازخورد پاسخ
- ده رکورد برتر محلی
- رابط فارسی راست‌چین و سازگار با موبایل

## اجرای محلی
```bash
npm install
npm run build
```

## ساخت اندروید
```bash
npm install
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

خروجی APK در مسیر `android/app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## هویت و نام‌گذاری
نام نمایشی برنامه «محاسبات ریاضی» است و نام لاتین همراه آن «MATH DASH» باقی می‌ماند. عنوان رسمی و نام پدیدآورنده نباید تغییر کند.


## وضعیت انتشار 0.1.3
- اصلاح چیدمان نشانهٔ پرسش فارسی با جداسازی دوسویهٔ متن (Bidi isolate).
- حذف بارگذاری فونت از Google Fonts برای حذف وابستگی شبکه‌ای و بهبود اجرای آفلاین.
- آغاز مستقیم هر حالت با لمس دکمهٔ همان حالت.
- چالش روزانهٔ ۴۰ پاسخ صحیح با محدودیت زمانی انتخاب‌شده در تنظیمات (۱، ۲ یا ۳ دقیقه).
- حریم خصوصی: رکوردها و زبان انتخابی فقط در حافظهٔ محلی دستگاه ذخیره می‌شوند.

نسخهٔ انتشار فروشگاهی هنوز باید با کلید اختصاصی توسعه‌دهنده امضا و روی دستگاه واقعی آزمایش شود؛ APKهای Debug برای انتشار فروشگاهی نیستند.
